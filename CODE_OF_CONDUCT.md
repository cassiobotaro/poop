# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct.

## Scope

The covenant applies within all project spaces — issues, pull requests, commit
messages, discussions, and any communication channel where someone is acting on
behalf of the project.

## Reporting

To report concerns, contact the maintainer at **cassiobotaro@gmail.com**.
Reports are handled privately. Reporters will not be identified without their
explicit consent.

## Enforcement

The maintainer is responsible for clarifying and enforcing the standards of
acceptable behavior described in the linked covenant, and will take action they
deem appropriate and fair in response to any behavior they consider
inappropriate, threatening, offensive, or harmful.
